# Backend Glossary

| 용어 | APMS-SR에서의 의미 | 관련 영역 |
|---|---|---|
| Authentication | 사용자 인증 | Security |
| Authorization | 권한 검증 | Security |
| User | 시스템 사용자 | IAM |
| Role | 사용자 역할 | RBAC |
| Permission | 권한 단위 | RBAC |
| RBAC | Role 기반 권한 관리 | IAM |
| Migration | DB Schema 변경 단위 | Flyway |
| Schema | Database 구조 | Database |
| PK | 테이블 식별자 | Database |
| FK | 테이블 관계 | Database |
