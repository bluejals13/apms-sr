# APMS.SR Data Layer Evidence Index

> 데이터 계층 관련 요구사항·설계·구현·테스트·실행 증거를 연결하는 Evidence Index이다.
> 상세 내용은 각 원본 문서와 소스 코드를 참조한다.

---

## 1. Evidence Chain

```text
PRD
 ↓
ADR
 ↓
Source Code
 ↓
Test
 ↓
Runtime Evidence
```

각 Claim은 위 Evidence Chain을 통해 추적한다.

## 4. Verification Status

| Status     | Meaning                                      |
| ---------- | -------------------------------------------- |
| `VERIFIED` | Required evidence chain is complete          |
| `PARTIAL`  | 일부 Evidence Chain이 존재하지만 Runtime 등 일부 증거가 없음 |
| `PLANNED`  | 검증 예정                                        |

**주의:** `VERIFIED`는 단순히 Source가 존재한다는 의미가 아니다. 해당 Claim에 요구되는 Evidence Chain이 모두 충족된 경우에만 사용한다.

---

## 5. Evidence Boundary

이 문서는 상세 구현 설명이나 실행 로그를 저장하지 않는다.

* PRD → 요구사항의 원본
* ADR → 설계 결정의 원본
* Source → 실제 구현
* Test → 자동화 검증
* Runtime Evidence → 실제 실행 결과
* Reproduction → 재현 절차

본 문서는 위 자료들을 연결하는 **Index / Traceability Layer**이다.
