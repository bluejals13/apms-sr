여기서 나온 commit SHA + Docker container 상태를 실행환경에 기록한다.

4. 401과 403을 반드시 분리

이건 네 RBAC 증명에서 중요하다.

인증 자체가 없음
→ 401

인증은 됐지만 권한 없음
→ 403

인증 + 필요한 Permission 있음
→ 200

따라서 단순히 “접근 성공/실패”만 기록하지 말고 실제 HTTP status를 기록해야 한다.

5. DB/Redis는 “필요한 행”에만 붙인다

모든 AC마다 DB를 조회할 필요는 없다.

+

정도로 충분하다.

즉 증명에 필요한 Runtime 상태만 조회한다.
